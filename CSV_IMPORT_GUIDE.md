# CSV Data Import Guide

Your CareerRai app now has **bulk import capability** to add students and mentors from CSV files!

## ✅ What It Does

- **Bulk Create Users**: Import multiple students & buddies at once from a CSV file
- **Auto-Assign Buddies**: Optionally assign buddies to students in the import
- **Validate Data**: Checks email format, required fields, no duplicates
- **Generate Passwords**: Creates temporary passwords (users can reset on first login)
- **Detailed Reporting**: Shows exactly what succeeded, what failed, and why

## 📋 Data Format Required

Your CSV file needs exactly these columns (in any order):

```csv
full_name,email,phone,role,exam_target,buddy_email
```

### Column Details:

| Column | Required? | Example | Notes |
|--------|-----------|---------|-------|
| `full_name` | ✅ Yes | "Aarav Sharma" | Student/buddy's full name |
| `email` | ✅ Yes | "aarav@careerrai.com" | Must be unique, not already in system |
| `phone` | ✅ Yes | "+91-9876543210" | Phone number (any format) |
| `role` | ✅ Yes | "student" or "buddy" | Must be exactly one of these |
| `exam_target` | ✅ For students | "CAT" or "CUET" | Leave blank for buddies |
| `buddy_email` | ❌ Optional | "nishant@careerrai.com" | Email of buddy (if assigning). Must exist in import |

## 📝 Example CSV (Real Data)

```csv
full_name,email,phone,role,exam_target,buddy_email
Aarav Sharma,aarav@careerrai.com,+91-9876543210,student,CAT,nishant@careerrai.com
```

In this example:
- 3 students assigned to 2 buddies
- 1 buddy (Nishant) assigned to 2 students
- Each buddy references their email in the `buddy_email` column

## 🎯 Step-by-Step Import Process

### Step 1: Prepare Your CSV File

**Option A: Download Template**
- Go to Admin Dashboard → Data Management section
- Click "Template" button to download `careerrai-import-template.csv`
- Open in Excel/Google Sheets
- Fill in your student/buddy data

**Option B: Create Manually**
- Create CSV file with headers shown above
- Can use Excel and "Save As → CSV format"
- Or use Google Sheets → Download as CSV

### Step 2: Validate Your Data

Before uploading, check:
- ✅ All students have `exam_target` (CAT or CUET)
- ✅ All buddies have blank `exam_target` 
- ✅ All emails are unique (no duplicates across all rows)
- ✅ No emails already exist in CareerRai system
- ✅ If using `buddy_email`, that email is in the same import (can't reference existing buddies yet)
- ✅ All required columns present (full_name, email, phone, role)

### Step 3: Upload to Admin Dashboard

1. Log in as admin (admin@careerrai.com)
2. Go to **Admin Dashboard** (home page after login)
3. Scroll to **Data Management** section
4. Select your CSV file from computer
5. Click **"Upload & Import"** button
6. Wait 10-30 seconds for processing

### Step 4: Review Results

After upload, you'll see:

**✓ Summary Stats:**
- Total rows processed
- How many successfully created
- How many failed

**✓ Created Users List:**
- Email address
- Role (student/buddy)
- Full name
- Can copy emails for initial login

**✓ Errors (if any):**
- Which rows had problems
- Exact reason why (invalid email, missing field, etc.)
- Fix errors and re-upload those rows

**✓ Buddy Assignment Errors:**
- If buddy assignment failed for any students
- Usually means the buddy email wasn't found

## 🔐 What Happens After Import

1. **Auth users created**: System creates login accounts for all users
2. **Profiles created**: User profiles stored with name, phone, role, exam_target
3. **Temporary passwords**: Each user gets a random secure password
4. **Buddy assignments**: Students are linked to their buddy if specified
5. **Ready to login**: All users can log in immediately with email + temp password

### For First-Time Login:

Send each user:
```
Email: [their email from CSV]
Temporary Password: [generated by system]
Login URL: https://careerrai-daily.vercel.app/login
```

They can then:
1. Log in with email + temp password
2. Change password in their Profile settings
3. Start using the app

## 🚨 Common Errors & Fixes

### Error: "Invalid email"
- **Reason**: Email format wrong or missing @ symbol
- **Fix**: Check email column for typos

### Error: "Missing exam_target"
- **Reason**: Role is "student" but exam_target is blank
- **Fix**: Add "CAT" or "CUET" for all students

### Error: "Duplicate email"
- **Reason**: Same email appears twice in CSV
- **Fix**: Check for duplicate rows, remove one

### Error: "Email already exists"
- **Reason**: Email already in CareerRai system (from previous import or seed data)
- **Fix**: Use different email or delete existing user and re-import

### Error: "Role must be 'student' or 'buddy'"
- **Reason**: Role column has different value (e.g., "mentor" or "Buddy")
- **Fix**: Change to exactly "student" or "buddy" (lowercase)

### Error: "Buddy '[email]' not found in import"
- **Reason**: buddy_email references someone not in this CSV
- **Fix**: Either include the buddy in this import OR leave buddy_email blank and assign manually in admin dashboard

## 💡 Advanced Tips

### Partial Imports
If some rows have errors:
- System only creates valid rows
- Invalid rows are skipped (not created)
- Fix errors in CSV and re-import the bad rows

### Updating Assignments
To assign a buddy to an existing student:
1. Use the Admin Dashboard "All Students" section
2. Click dropdown next to student name
3. Select buddy from list
4. Auto-saves

### Bulk Changes
For changes to multiple students (e.g., change all students' exam target):
- Edit CSV file
- Create new import with just those rows

### No Duplicate Check Across Systems
⚠️ **Important**: The import checks for duplicates **within the CSV file** and **in the system**
- If you re-upload same CSV twice, second upload will fail (emails already exist from first import)
- To re-import: use different emails or manually delete users first

## 📊 What Gets Imported vs What Doesn't

**✅ Gets Imported:**
- User authentication credentials (email, password)
- Profile information (name, phone, role, exam_target)
- Buddy assignments
- User creation timestamp

**❌ Does NOT Get Imported:**
- Daily reports (students need to submit these)
- Test results (add separately after import)
- Feedback (buddies add after students submit reports)
- Notification history
- Preference settings

These are user-generated data that must be created through the app.

## 🆘 Need Help?

### Import Failed Completely
Check:
1. Is file actually CSV format? (not .xlsx)
2. Is first row the header row?
3. Do all required columns exist?
4. Are you logged in as admin?

### Some Users Created, Some Failed
This is normal. Review the error list and:
1. Fix the errors in the CSV
2. Re-upload just those rows with different data

### Want to Undo an Import
Unfortunately, there's no undo. But you can:
1. Delete individual users from Supabase dashboard (advanced)
2. OR change their emails/passwords through admin
3. OR contact support
