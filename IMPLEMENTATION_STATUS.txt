================================================================
TROUBLESHOOTING
================================================================

If Diagnostic Page Shows ✗:
1. Check browser console (F12 → Console tab)
2. Verify Supabase connection
3. Check microphone permissions
4. Ensure storage bucket exists
5. Confirm database migration completed

If Recording Fails:
1. Enable microphone in browser
2. Check Chrome → Settings → Privacy → Microphone
3. Verify network connectivity
4. Check Supabase storage bucket status
5. Review browser console errors

If Playback Doesn't Work:
1. Verify audio file uploaded (check storage bucket)
2. Check voice_note_url in database
3. Confirm browser audio permissions enabled
4. Try different browser
5. Clear cache and reload page

If No Data Appears:
1. Wait 5-10 seconds for database sync
2. Refresh page (Ctrl+R or Cmd+R)
3. Check both student and buddy accounts logged in
4. Verify RLS policies in Supabase
5. Check database for records in buddy_feedback table
